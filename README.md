# Belgee Tracker 🚗⚡

Умный трекер расходов для гибридного автомобиля Belgee X80 PHEV.

## Функции:
- Учет заправок (Бензин) и зарядок (Электро).
- Учет тарифов по времени (День/Ночь) и сетям зарядок (Malanka, ZARYADKA и др.).
- Ввод остатка бака в процентах с автопересчетом в литры (по схеме бака Geely EX5).
- Аналитика: стоимость 1 км, средний расход, графики Chart.js.
- Интеграция с Home Assistant (через Webhook).

## Установка на iPhone:
1. Откройте ссылку на GitHub Pages в Safari.
2. Нажмите «Поделиться» -> «На экран «Домой»».
